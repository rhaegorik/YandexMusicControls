# 🎵 Yandex Music Controls for BetterDiscord

Плагин для BetterDiscord, который добавляет элегантную панель управления Яндекс Музыкой прямо над вашим профилем в Discord. Дизайн полностью повторяет популярный плагин SpotifyControls.

## ✨ Возможности
* 🎨 **Стильный интерфейс**: Панель с обложкой трека, названием, исполнителем и таймлайном.
* ⏯ **Полное управление**: Кнопки Play/Pause, Next, Prev работают напрямую с вашим плеером.
* 📐 **Адаптивность**: При клике на обложку панель разворачивается, показывая картинку в большом квадратном размере.
* 🌓 **Поддержка тем**: Интерфейс автоматически подстраивается под светлую или темную тему Discord.

---

## ⚠️ ВАЖНО: Необходимая программа

Этот плагин **НЕ УМЕЕТ** самостоятельно получать информацию о треках из Яндекс Музыки. Он лишь красиво отображает то, что уже передается в ваш профиль Discord.

Для работы вам **ОБЯЗАТЕЛЬНО** нужна программа **[WinYandexMusicRPC](https://github.com/Feodor0090/WinYandexMusicRPC)** (или её аналоги), которая транслирует прослушиваемую музыку в статус Discord (Rich Presence).

**Без запущенного RPC-приложения плагин будет пустым!**

---

## ⚙️ Принцип работы

Проект состоит из двух частей, которые работают в связке:

1. **Плагин (JavaScript)**: Находится внутри Discord, считывает статус активности, который передает `WinYandexMusicRPC`, и отрисовывает панель управления.
2. **Мост (PowerShell)**: Так как плагины Discord не имеют прямого доступа к системе, при нажатии на кнопки плагин отправляет локальный HTTP-запрос на скрипт-мост (`YandexMusicBridge.ps1`). Мост, в свою очередь, эмулирует нажатие медиа-клавиш клавиатуры (Play/Pause/Next), заставляя Яндекс Музыку реагировать.

## 📥 Установка

1. Скачайте все файлы из этого репозитория и поместите их в **одну папку** (например, `YandexMusicBridge`).
2. Переместите файл `YandexMusicControls.plugin.js` в папку плагинов BetterDiscord:
   * **Windows:** `%appdata%\BetterDiscord\plugins`
3. Включите плагин в настройках Discord (BetterDiscord -> Plugins).

## 🚀 Использование

1. Запустите программу **WinYandexMusicRPC**.
2. Запустите файл **`StartHidden.vbs`** (он запустит мост в фоне без лишних окон).
3. Включите музыку в Яндекс Музыке. Панель в Discord появится автоматически.

### 🛠 Управление мостом (вспомогательные файлы)

* **`1_Install_Autostart.bat`** — запустите один раз, чтобы мост автоматически запускался при включении компьютера.
* **`2_Remove_Autostart.bat`** — удаляет мост из автозагрузки.
* **`3_Kill_Bridge.bat`** — если мост завис или кнопки перестали работать, запустите этот файл, чтобы принудительно остановить все фоновые процессы. После этого снова запустите `StartHidden.vbs`.

## 📦 Файлы в репозитории

* `YandexMusicControls.plugin.js` — Сам плагин для BetterDiscord.
* `YandexMusicBridge.ps1` — Скрипт-мост для приема команд.
* `StartHidden.vbs` — Скрытый запуск моста.
* `1_Install_Autostart.bat` / `2_Remove_Autostart.bat` — Установка/удаление автозагрузки.
* `3_Kill_Bridge.bat` — Экстренная остановка моста.
